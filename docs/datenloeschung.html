Anleitung zur Datenlöschung

Die App „krass-erforscht“ speichert keine personenbezogenen Daten von Instagram-Nutzenden – nur die technische Kennnummer eines Kommentars, nachdem er beantwortet wurde.

So kannst du Daten löschen lassen:

  1. Lösche deinen Kommentar unter dem Beitrag von @krass.erforscht direkt in Instagram. Damit ist er auch für die App nicht mehr abrufbar.
  2. Wenn du zusätzlich möchtest, dass auch die gespeicherte Kennnummer gelöscht wird, schreib eine Direktnachricht an @krass.erforscht mit dem Wort „Löschung“. Die Kennnummer wird innerhalb von 30 Tagen entfernt und du bekommst eine Bestätigung.

Data Deletion Instructions

The app “krass-erforscht” does not store personal data of Instagram users – only the technical ID of a comment after it has been replied to.

  1. Delete your comment on the @krass.erforscht post directly in Instagram; the app can then no longer access it.
  2. To also have the stored comment ID removed, send a direct message with the word “deletion” to @krass.erforscht on Instagram. It will be removed within 30 days and you will receive a confirmation.
